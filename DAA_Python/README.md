# DAA Python Application

A Tkinter desktop application demonstrating core DAA concepts in the Campus Event and Venue Management System.

## Algorithms demonstrated

1. **Linear search** is not used here; event lookup uses **Binary Search** after sorting event names.
2. **Merge Sort** sorts events by date.
3. **Greedy venue allocation** selects the smallest available venue that can accommodate the event.

## Run

```bash
python campus_event_system.py
```

No third-party Python packages are required.
